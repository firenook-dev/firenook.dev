Firenook runs your Firebase project locally from the files you already have:
the same `firebase.json`, rules and Functions code, the same client and Admin
SDKs, and the same ports. It serves Firestore, Authentication, Cloud Storage,
Cloud Functions, Extensions, Pub/Sub, Cloud Tasks and Eventarc from one npm
package, with no Java and nothing else to download.

## Status

Firenook is in preview: its releases are `0.2.0-next` versions on npm. Every
release passes conformance replays against the official emulator and packed
installs on all five platforms. Pin an exact version and upgrade on purpose.
