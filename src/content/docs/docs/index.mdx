Firenook is a drop-in replacement for the Firebase Local Emulator Suite. It
runs your project from the files you already have: the same `firebase.json`,
rules and Functions code, the same client and Admin SDKs, and the same ports.
It serves Firestore, Authentication, Cloud Storage, Cloud Functions,
Extensions, Pub/Sub, Cloud Tasks and Eventarc from one npm package, with no
Java and nothing else to download.

## Status

These docs describe Firenook `0.2.0`, the first release for public use. It
runs on Node 22, 24 or 26, on macOS (Apple silicon and Intel), Linux x64 and
arm64 with glibc 2.28 or newer, and Windows x64. Every release passes
conformance replays against the official emulator and packed installs on all
five platforms. Pin an exact version and upgrade on purpose; see
[versions and verification](/docs/help/versions).

Realtime Database, Hosting, App Hosting and Data Connect are not emulated. A
`firebase.json` that configures them still starts, with a warning.
[Compatibility](/compatibility) records what each service covers and what it
does not.
